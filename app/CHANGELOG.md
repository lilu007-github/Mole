# Burrow 更新说明

每个版本的第一行是 `## 版本号 — 日期`，版本号要和 `app/VERSION` 一致（检查会核对）。

## 0.3.0 — 2026-10-22

- 新页面「应用更新」：Homebrew 和 App 自带更新渠道，可忽略某个 App、一键全部更新
- 新页面「启动项」：列出后台启动项和失效项，只读
- 磁盘分析新增方块图视图，鼠标指到哪块，下方就显示它的名称和大小
- 清理新增白名单管理和外置磁盘清理
- 系统状态：进程详情和退出、闲置的开发进程、摄像头和麦克风使用提示、拷贝 IP
- AI 数据新增 Claude Code / Codex 工作树清单，只读
- 卸载正在运行的 App 前先提示退出
- 诊断新增性能诊断
- 开机自启、全局快捷键、通知、菜单栏指标、推出外置磁盘、隐藏 Dock 图标、⌘Q 只关窗口、外观、⌘1–9 切换页面
- 首次启动权限指南
- 关于窗口显示版本号和更新说明
- 说明 Burrow 与 Mole 项目没有隶属关系

## 0.2.0 — 2026-10-22

- 内置 Mole CLI，不再依赖单独安装的 mo
- 本机自签名证书签名，重新打包后系统权限不会丢
- 新页面：AI 数据、历史记录、构建产物
- 卸载时可以选择要删除的个人数据
- 诊断、清洁屏幕、关于和 Mole 更新检查
- 应用图标、自动化检查和同步原作者更新的脚本

## 0.1.0 — 2026-10-22

- 第一个版本：系统状态、磁盘分析、清理、优化、安装包、卸载应用
- 菜单栏面板和保持常亮
- 系统拒绝权限时说明原因和去哪里打开
